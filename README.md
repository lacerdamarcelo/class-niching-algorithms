# Niching Algorithms - Lecture Slides
This repository includes the "slides" I used to give a lecture about Niching Algorithms at University of Pernambuco on November 10th, 2025.

The slides are actually plotly dashboards. To see their content, you need to run `python app.py` after installing the depencies in requirements.txt.

Implemented with the aid of Sonnet 4.5!
